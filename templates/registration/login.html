Traffic Monitoring System

Developed by Shreyas, Prashanth, Saurabh for Software Engineering Course

The Real-Time Traffic Monitoring System is an end-to-end software solution designed to ingest live video feeds from road intersections, process frame sequences using computer vision algorithms, and output real-time traffic statistics (vehicle counts, flow density, and queue length). The system bridges low-level video processing with a responsive frontend dashboard, enabling traffic operators to visualize density trends, receive automated congestion alerts, and manage system access securely.
